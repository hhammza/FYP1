Analytical Tool

Biological Simulation

Not a machine learning model a mathematical simulation tool based on published biological kinetics.

Mutation Timeline Simulator
Logistic Growth Equation · Biologically Calibrated
Simulation
This is not an ML model. Predictions are generated by a logistic growth equation parameterised with empirically calibrated antibiotic-specific constants, not learned from data.

Simulates week-by-week resistance evolution under antibiotic pressure using the logistic growth equation: R(t) = R₀ + (R_peak − R₀) / (1 + e−k(t−t₀))

Each antibiotic has calibrated parameters (growth rate k, peak resistance, midpoint). An optional FASTA file adjusts the curve via genome GC content; a higher GC deviation suggests higher baseline mutation pressure.

How it differs from ML models

Methodology

How the System Works

Two trained ML models for resistance prediction, plus one mathematical simulation tool for visualising resistance evolution over time.

01
Data Collection: BVBRC/PATRIC
AMR phenotype records (Resistant/Susceptible/Intermediate) linked to bacterial genome metadata including MIC values, laboratory methods, and FASTA genome sequences from the BVBRC database.
02
Feature Engineering: K-mer Spectra
Bacterial genomes are converted to 4-mer frequency vectors (256 dimensions). Each genome produces a fixed-length fingerprint capturing codon composition, GC content, and repeat patterns. No reference genome is needed.
03
LightGBM: Tabular Metadata
For records without FASTA files, a LightGBM gradient boosted tree model uses tabular features: MIC value, antibiotic identity, drug class, organism taxonomy, and cross-encoded resistance rates per antibiotic.
04
Class Imbalance Correction
Training data is typically imbalanced (more Susceptible than Resistant isolates). LightGBM uses is_unbalance=True and the K-mer RandomForest uses class_weight='balanced', improving recall for resistant strains without synthetic oversampling.
05
Bio-Simulator: Logistic Growth Not ML
Resistance spread follows logistic kinetics. The timeline simulator uses a mathematical equation, not trained on data, to show week-by-week resistance evolution per antibiotic. It complements the ML predictions with temporal context.
06
Validation: AUC-ROC & F1
Both trained models achieve AUC-ROC ≥ 0.93 on held-out test sets. Threshold tuning via precision-recall curves optimises the F1 score for clinical utility by balancing sensitivity (catching true resistance) against specificity.
Get Started

Quick Start Guide

01
Train Models (optional)

Models are pre-trained. To retrain on your dataset, go to Train Models or run python train_models.py --model all in the backend folder.

02
AMR Forecasting

Go to AMR Forecasting and enter an antibiotic name, MIC value, and organism genus/species. The LightGBM model returns resistance probability instantly.

03
Genome-level Analysis

Upload a .fasta file to Resistance Prediction for k-mer analysis, or to Mutation Timeline for a week-by-week evolution forecast.
