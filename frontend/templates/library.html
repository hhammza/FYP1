Forecast from metadata LightGBM

Use when you have organism metadata and, ideally, an MIC measurement. This is the strongest of the three models.

Python 
import amrpredict

r = amrpredict.forecast(
    'ciprofloxacin',
    taxon_id=562,        # NCBI taxonomy ID (562 is E. coli)
    mic_value=4,         # mg/L
    genus='Escherichia',
    species='coli',
)

print(r['prediction'])   # 'Susceptible'
print(r['confidence'])   # 89.9
Predict from a genome K-mer RF

Use when sequence is all you have. FASTA is cleaned to plain ACGT and capped at 500,000 bp.

Python 
with open('genome.fasta') as fh:
    r = amrpredict.predict_fasta(fh.read(), 'ciprofloxacin')

if 'error' in r:
    print('bad input:', r['error'])
else:
    print(r['prediction'], r['gc_content'])

Short or empty input returns an error key instead of a prediction. It never raises, so check for it first.

Simulate resistance evolution Simulation
This is a deterministic biological simulation, not a trained model. It carries no AUC or accuracy score, so treat its output as illustrative.
Python 
r = amrpredict.simulate_timeline(fasta, 'ciprofloxacin', n_weeks=8)

for w in r['timeline']:
    print(w['week'], w['resistant_fraction'], w['mic_fold_change'])

print(r['failure_week'])      # when treatment stops working
print(r['resistance_genes'])  # gyrA, gyrB, parC ...

n_weeks=8 returns 9 entries. Week 0 is the untreated baseline.

Command line

Every command prints JSON to stdout; diagnostics go to stderr, so output pipes cleanly.

Terminal 
amrpredict forecast ciprofloxacin --taxon-id 562 --mic-value 4
amrpredict predict genome.fasta ciprofloxacin --threshold 0.6
amrpredict timeline genome.fasta ciprofloxacin --weeks 12
amrpredict antibiotics
amrpredict status

# composes with jq
amrpredict --compact forecast meropenem --taxon-id 287 | jq -r .prediction
cat genome.fasta | amrpredict predict - ciprofloxacin

Choosing a threshold

threshold is the probability at or above which a sample is called Resistant. It changes the label, never the underlying probability.

0.3
Higher sensitivity
More resistance calls. Use when missing resistance is costly.
0.4
Forecast default
Balanced for the LightGBM model.
0.5
K-mer default
Balanced for genome-based prediction.
0.7
Higher specificity
Fewer, more confident calls. Use when false alarms are costly.
Your own models

Every entry point accepts model_dir:

Python 
amrpredict.forecast(
    'ciprofloxacin', taxon_id=562,
    model_dir='/path/to/models',
)

Retrain artifacts with train_models.py.

Compatibility

The k-mer model is a pickled scikit-learn estimator, so the dependency is pinned to >=1.3,<2.0. Unpickling across a major version is unsupported and would produce wrong numbers rather than failing loudly.

Artifacts were built with scikit-learn 1.6.1. The LightGBM model is unaffected, because it uses LightGBM's own version-stable text format.
