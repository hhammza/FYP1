How we split train and test

Each genome is tested against about {{ s.rows_per_genome }} antibiotics, so it appears in about {{ s.rows_per_genome }} rows. The split is made by genome, not by row, so no genome is ever in both training and test.

The procedure
1
Test set. StratifiedGroupKFold with 5 folds, grouped by Genome ID. One fold (20% of genomes) becomes the test set.
2
Validation set. The training genomes are split again into {{ s.validation_folds }} grouped folds. One is held out for early stopping and the threshold.
3
Rate features. Resistance rates per drug, taxon and genus are computed out of fold ({{ s.encoding_folds }} grouped folds), so a row never sees its own label.

Stratified. Train and test keep the same resistant share: {{ '%.1f' | format(100 * g.train_prevalence) }}% and {{ '%.1f' | format(100 * g.test_prevalence) }}%.

Learning curve

LightGBM AUC as training data grows. It flattens early, so more rows alone will not fix it.

The error trade-off

VME (very major error) is a resistant isolate called susceptible, the dangerous mistake. ME (major error) is a false resistant call. Moving the threshold trades one for the other, which is why A2 (threshold 0.40) and A9 (0.47) share an AUC but sit far apart here.

Reading these scores
  • Lab AUC uses only rows with a real lab result. BV-BRC's computer-predicted labels were made from the genome itself, so scoring on them would reward copying.
  • Split: grouped keeps each genome on one side; lineage also keeps near-identical isolates together, so outbreak clones cannot leak; species_holdout tests on a whole genus the model never saw.
