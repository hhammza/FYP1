What this page shows

Our K-mer model counts DNA letter patterns; it does not know which gene causes resistance. AMRFinderPlus {{ run.amrfinder_version or '' }} (database {{ run.database_version or 'unknown' }}), NCBI's own tool, searched each complete assembly for known resistance genes and resistance mutations (only core AMR elements: {{ run.filter }}). These results become gene features for the next models, and they can explain a prediction: resistant because blaCTX-M-15 is present.
